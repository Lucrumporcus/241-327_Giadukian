# Конспект

## 1. Определения

CRUD - Create, Read, Update, Delete
REST (Representational State Transfer) - архитектурный стиль взаимодействия клиента и сервера через HTTP.
Приложение Django - модуль внутри проекта, реализующий отдельную функциональность.
Django - веб-фреймворк на Python для быстрой разработки серверных приложений.
ASGI (Asynchronous Server Gateway Interface) - стандартный интерфейс для связи между веб-серверами и асинхронными веб-приложениями.
WSGI (Web Server Gateway Interface) — это стандарт взаимодействия между веб-сервером и веб-приложением.
URL (Uniform Resource Locator - унифицированный указатель ресурса) — это уникальный адрес конкретного файла, страницы или объекта.
URI (Uniform Resource Identifier) - строка символов, которая унифицированно идентифицирует физический или абстрактный ресурс в сети. 
Транзакция — группа операций с БД, выполняемая как единое целое.
Миграции БД — механизм версионирования схемы базы данных.

**ORM - Object-Relational Mapping**
ORM — это технология и библиотека, которая связывает объекты языка программирования (классы, экземпляры) с таблицами реляционной базы данных. Разработчик работает с объектами Python, а ORM автоматически преобразует эти операции в SQL-запросы.

библиотеки: DjangoORM, SQLAlchemy

принципы работы: каждый класс описывает таблицу в БД, имя класса обычно соотв. имени таблицы. поля класса становятся колонками таблицы с соотв. типами SQL. один объект python соответствует одной записи в таблице. ForeignKey, ManyToManyField и т.п. преобразуются в FOREIGN KEY, промежуточные таблицы и JOIN-запросы. Когда вы вызываете Book.objects.filter(year__gt=2000), ORM генерирует SQL вида: SELECT * FROM book WHERE year > 2000;. ORM отслеживает изменения в классах моделей и создаёт миграции — файлы, которые описывают, как изменить схему БД (создать/удалить таблицу, добавить столбец и т.д.).

преимущества: скорость разработки, безопасность, удобство.
недостатки: требовательно к производительности, сложные запросы проще писать на чистом SQL

ниши: веб-приложения, прототипирование
альтернативы: ручные миграции, специализированные инструменты миграции (Alembic и тд.)
